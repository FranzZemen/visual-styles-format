# visual-styles-format — usage

```ts
import {
  parseVisualStyles, validateVisualStyles, generateCss, generateTailwindTheme, formatVisualStyles,
  resolveEntry, followersOf, describeValue, diffVisualStyles, contentHash, readGeneratorStamp,
  findEntry, VisualStylesInvalidError,
} from '@franzzemen/visual-styles-format';

const {file, errors} = parseVisualStyles(readFileSync('src/styles/visual-styles.json', 'utf8'));
if (!file) throw new Error(errors.map(e => `${e.path}: ${e.message}`).join('\n'));

writeFileSync('src/styles/visual-styles.json', formatVisualStyles(file));   // canonical text
writeFileSync('src/styles/visual-styles.css', generateCss(file));
writeFileSync('src/styles/visual-styles.theme.css', generateTailwindTheme(file));
```

(broken-stock's `scripts/visual-styles-generate.mjs` does exactly this. visualstyles-app writes the
same three texts.)

## A small file and what it generates

```json
{"formatVersion": 1, "entries": [
  {"name": "surface", "kind": "colour", "group": "Meaning", "description": "Background", "value": "#161b22"},
  {"name": "profit.text", "kind": "colour", "group": "Meaning", "description": "Profit text",
   "value": "#1b5e20", "legacyName": "--color-profit", "tailwind": true},
  {"name": "series-1", "kind": "colour", "group": "Meaning", "description": "Default line 1", "value": "#2caffe"},
  {"name": "since.unrealized", "kind": "colour", "group": "Since chart", "description": "Unrealized line",
   "follow": {"target": "series-1"},
   "chart": [{"scope": ".bs-chart-since", "selector": ".bs-s-unrealized .highcharts-graph", "property": "stroke"}]},
  {"name": "since.unrealized-zero", "kind": "colour", "group": "Since chart", "description": "Zero line",
   "follow": {"target": "since.unrealized", "opacity": 40}},
  {"name": "chart.line.width", "kind": "number", "group": "All charts", "description": "Line width",
   "value": 1.5, "unit": "px"}
]}
```

`generateCss(file)`:

```css
/* Generated by @franzzemen/visual-styles-format 1.0.0 (format 1) from visual-styles.json. Do not edit. */

:root {
  --vs-chart-line-width: 1.5px;
  --vs-profit-text: #1b5e20;
  --vs-series-1: #2caffe;
  --vs-since-unrealized: var(--vs-series-1);
  --vs-since-unrealized-zero: color-mix(in srgb, var(--vs-since-unrealized) 40%, transparent);
  --vs-surface: #161b22;
}

/* Existing names, taken over (D11): each points at its entry. */
:root {
  --color-profit: var(--vs-profit-text);
}

/* Chart rules (D12): by role class name, never by position. */

.bs-chart-since .bs-s-unrealized .highcharts-graph {
  stroke: var(--vs-since-unrealized);
}
```

`generateTailwindTheme(file)`:

```css
/* Generated by @franzzemen/visual-styles-format 1.0.0 (format 1) from visual-styles.json. Do not edit. */

@theme inline {
  --color-profit: var(--vs-profit-text);
}
```

## Validation

```ts
validateVisualStyles(input);        // ValidationError[] — empty means valid
// [{path: 'entries[2].value', entry: 'series-1', code: 'forbidden-text', message: 'contains forbidden text ";"'},
//  {path: 'entries[6].follow', entry: 'a', code: 'follow-loop', message: 'follow loop: a → b → a'}]

parseVisualStyles('{').errors;      // [{path: '$', code: 'not-json', message: 'not JSON: …'}]

try { generateCss(bad); } catch (e) { if (e instanceof VisualStylesInvalidError) e.errors; }
```

`isValidVisualStyles(x)` is a type guard. `assertValidVisualStyles(x)` returns the file or throws.
Error codes are the `ValidationCode` union in `types.ts`.

## Helpers

```ts
resolveEntry(file, 'since.unrealized-zero');
// {kind: 'colour', chain: ['since.unrealized-zero', 'since.unrealized', 'series-1'], ownValue: '#2caffe',
//  opacity: 0.4, rgba: {r: 44, g: 175, b: 254, a: 0.4}, css: 'rgba(44, 175, 254, 0.4)'}

followersOf(file, 'series-1');                       // ['since.unrealized']
followersOf(file, 'series-1', {transitive: true});   // ['since.unrealized', 'since.unrealized-zero']
describeValue(findEntry(file, 'since.unrealized-zero')!);   // 'follows since.unrealized at 40%'

diffVisualStyles(before, after);
// [{name: 'series-1', change: 'changed', before, after, beforeText: '#2caffe', afterText: '#ff0000', valueOnly: true}]

await contentHash(file);                 // sha256 hex of canonicalJson(file); key order and whitespace do not matter
readGeneratorStamp(css);                 // {version: '1.0.0', formatVersion: 1}
```

| Function | Returns |
|---|---|
| `parseVisualStyles(text)` | `{file?, errors}` |
| `validateVisualStyles(x)` / `isValidVisualStyles(x)` / `assertValidVisualStyles(x)` | errors / boolean / file or throw |
| `generateCss(file, {version?})` | `visual-styles.css` text (throws when invalid) |
| `generateTailwindTheme(file, {version?})` | `@theme inline` block (throws when invalid) |
| `formatVisualStyles(file)` | canonical JSON text: fixed field order, 2-space indent, trailing newline |
| `cssValueOf(entry)` | right-hand side of the entry's `--vs-*` declaration |
| `resolveEntry(file, name)` | effective value through the follow chain, or `undefined` |
| `followersOf(file, name, {transitive?})` | names that follow `name` |
| `backgroundOf(entry)` | `entry.background ?? 'surface'` |
| `describeValue(entry)` | `#1b5e20`, `12px`, `follows series-1 at 40%` |
| `diffVisualStyles(before, after)` | `EntryChange[]`, sorted by name |
| `canonicalJson(x)` / `contentHash(x)` | stable text / `Promise<string>` sha256 hex |
| `generatorStamp(version?)` / `readGeneratorStamp(text)` | stamp line / `{version, formatVersion}` or `undefined` |
| `findEntry(file, name)` | the entry or `undefined` |
| `parseColour(text)` / `isValidColour(text)` / `formatRgba(rgba)` | `{r,g,b,a}` or `undefined` / boolean / `rgba(…)` |
| `cssVarName(name)` / `tailwindThemeName(name, legacyName?)` | `--vs-…` / `--color-…` |
| `isValidName`, `isValidLegacyName`, `isValidScope`, `isValidSelector`, `isAllowedProperty`, `forbiddenFragment` | grammar checks |
| `selectorElement`, `SELECTOR_ELEMENTS` | the element name a selector ends with (`text` for `.highcharts-button text`), and the allowed list |

Constants: `FORMAT_VERSION` (1), `NUMBER_UNITS`, `DEFAULT_BACKGROUND` (`'surface'`),
`COLOUR_PROPERTIES`, `NUMBER_PROPERTIES`, `NAME_PATTERN`, `LEGACY_NAME_PATTERN`, `MAX_*_LENGTH`,
`PACKAGE_NAME`, `PACKAGE_VERSION`.

## Releasing

```sh
npx bs.test
npx bs.patch -c "…"     # or bs.minor / bs.major; the version script restamps src/project/version.ts
```

Then bump `@franzzemen/visual-styles-format` in visualstyles-app, visual-styles and broken-stock, and
in broken-stock run `node scripts/visual-styles-generate.mjs` and commit the regenerated files,
because the stamp changed.
